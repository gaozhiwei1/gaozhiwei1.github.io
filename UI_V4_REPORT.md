# Math2LLM UI V4 Report

This pass focuses on compact, comfortable reading rather than dashboard-style cards.

## Learning pages
- Removed the visual feeling of stacked cards from ordinary knowledge nodes.
- Reduced title/body/formula spacing and tightened the right-side TOC.
- Reworked ordinary nodes into a continuous technical-note flow.
- Removed duplicated “motivation / mechanism / boundary” question-bank filler when it simply repeats node metadata.
- Boundary notes are now small inline caveats rather than full sections.
- Interview follow-ups are available in a collapsible section so they do not dominate the article.
- Gold articles use denser mathematical spacing and smaller hierarchy gaps.
- Added actual math and tensor-shape semantics to the foundational “向量与矩阵” node.

## Practice UI
- Made the question workspace, toolbar, options, filters, and answer pane more compact.
- Replaced the fragile Lucide circle-only selection marker with a stable custom radio indicator.
- Selected A/B/C/D options now keep a visible right-side dot before submit.
- Correct/wrong states still switch to check/x icons after submit.

## Scope
This is a UI and content-flow pass. It intentionally does not redesign auth/payment or change the 226-question / 33-coding curriculum.
